# 코리안리재보험 · Claude Cowork 교육

메가존클라우드 ISV BU / Data & AI CoE에서 코리안리재보험 정보기술팀 대상으로 진행하는 Claude Cowork 교육 자료입니다.

1부는 30분의 Cowork 소개 강의(`Claude_cowork_KoreanRe.html`), 2부는 90분의 핸즈온 세션(`코리안리_Cowork_실습가이드.html`)으로 진행합니다.

## 실습 데이터

참여자는 자기 트랙 폴더의 파일만 내려받습니다. 가이드 안의 다운로드 카드가 아래 경로를 직접 가리킵니다.

```
data/
├── A_계약원장_통합/          트랙 A · 파일 3개
│   ├── 01_계약원장_국내특약부.xlsx
│   ├── 02_계약원장_해외재보험부.xlsx
│   └── 03_계약원장_특종종목부.xlsx
├── B_문서_교차검증/          트랙 B · 파일 2개
│   ├── 01_문서_언더라이팅가이드.pdf
│   └── 02_계약원장_국내특약부.xlsx
└── C_반복업무_자동화/        트랙 C · 파일 1개
    └── 01_사고통계_담보별월별손해율.xlsx
```

**모든 데이터는 가상입니다.** 회사명, 계약번호, 금액, 담보 구분까지 전부 교육용으로 지어냈습니다.
실제 계약·사고·재무 데이터는 이 저장소에 올리지 않습니다.

폴더 이름을 바꾸면 가이드 안의 다운로드 링크가 끊깁니다. 파일을 교체할 때는
`코리안리_Cowork_실습가이드.html`의 `issu-ai.github.io/claude-edu/data/` 링크도 함께 고칩니다.

## 실습 구성

참여자는 트랙 하나를 골라 여덟 챕터를 순서대로 돕니다.

**Part 1 — 다 같이 한 바퀴**

| | 챕터 | 하는 일 |
|---|---|---|
| | 시작 | 준비 확인, 트랙 선택, 프로젝트 생성 |
| 1 | Plan | 일을 역할로 나누는 설계를 Claude와 함께 만든다 |
| 2 | 실행 | 설계한 순서대로 Agent를 구축하고 진행을 지켜본다 |
| 3 | Eval | 결과를 6항목 100점으로 채점한다 |
| 4 | 수정 | 실패한 항목을 지침 한 줄로 막고 다시 돌린다 |
| 5 | 자산화 | 스킬 · 프로젝트 지침 · 예약으로 남긴다 |

**Part 2 — 각자 자기 업무로**

| | 챕터 | 하는 일 |
|---|---|---|
| | 쉬어가기 | 규칙을 어디에 둘 것인가 |
| 6 | 내 업무 | 사전과제로 가져온 본인 업무를 같은 방식으로 |
| 7 | 발표 | 세 문장으로 나눈다 |
| 8 | 마무리 | 가져가는 한 장 |

체크 상태와 메모는 브라우저 `localStorage`에 남습니다. 서버로 나가지 않고, 참여자 본인 브라우저에만 있습니다.
