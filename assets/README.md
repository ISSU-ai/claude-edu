## 찍을 때

- 가로 **1600px 내외**, 창 전체가 아니라 **필요한 영역만** 잘라서
- **개인정보 · 실제 계정명 · 사내 파일명은 가릴 것** — 교육 자료는 배포됩니다
- 다크/라이트 모드는 **하나로 통일** (기존 Chat·Cowork·Code 캡쳐가 라이트)
- 실습용 `코리안리_Cowork_작업` 폴더로 세팅해두고 찍으면 슬라이드와 실습이 그대로 이어짐
- 형식은 **PNG**. 슬라이드에서 높이 300px로 맞춰 표시되므로 세로로 너무 긴 캡쳐는 피할 것

## 파일이 없을 때의 동작

- 화면에서는 점선 상자에 "캡쳐 자리 — 무엇을 찍을지"가 표시됩니다
- **인쇄 · PDF에서는 자동으로 빠집니다** (빈 상자가 PDF에 남지 않음)
- `03-schedule.png`만 예외 — 캡쳐가 없으면 기존 시계 도식이 대신 나옵니다
