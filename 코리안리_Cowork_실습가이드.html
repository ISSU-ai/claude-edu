# 계약 원장 작업 지침

## 용어
- 수재: 다른 보험사로부터 인수한 위험. 열 이름 re_assumed
- 출재: 다른 재보험사로 넘긴 위험. 열 이름 re_ceded
- 보유: 수재 - 출재
- 배서: 기존 계약의 변경분이다. 새 계약이 아니다.
  계약 건수를 셀 때 배서를 더하지 않는다.

## 산출물 표준
- 금액은 백만원 단위, 천 단위 콤마, 소수점 없음
- 모든 집계 표에 '출처 파일명'과 '원본 행 번호' 열을 반드시 포함한다
- 슬라이드의 숫자에는 각 장 하단에 출처를 작게 표기한다
- 날짜는 YYYY-MM-DD로 통일한다.
  원본 형식이 MM/DD/YYYY인지 DD/MM/YYYY인지 확실하지 않으면 물어본다.
- 통화 열을 먼저 확인한다.
  파일 이름이 '해외'라도 KRW 건이 섞여 있을 수 있다.

## 금지
- 원본 파일 수정 · 삭제 금지. 결과는 항상 output/ 폴더에 새 파일로 만든다
- 값을 추정하거나 채워 넣지 말 것. 모르면 빈칸 + '확인필요'
- 계산할 수 없는 값(0으로 나누기 등)은 빼지 말고 '산출불가'로 표기한다

전역 지침도 한 줄 넣어봅니다

폴더 지침은 그 폴더에서 일할 때만, 전역 지침은 내 모든 세션에 적용됩니다.
설정 > Cowork > Global instructions 에 넣습니다.

전역 지침
수치를 제시할 때는 항상 출처 파일명과 행 번호를 함께 적는다.
근거를 찾을 수 없으면 '근거 없음'이라고 명시하고 추정하지 않는다.
기억할 것

업무 규칙은 폴더 지침으로, 개인 습관은 전역 지침으로. 전역에 업무 규칙을 넣으면 팀이 볼 수 없습니다.
검토받을 수 없는 규칙은 규칙이 아닙니다.

  • Manual: 매 행동 승인 (오늘 실습 모드)
  • Auto: 읽기는 자동, 쓰기·삭제는 판단 (제품 기본값)
  • Skip: 전부 자동. 신뢰된 작업만
  • 삭제 · 외부 전송 · 메일은 항상 Manual
